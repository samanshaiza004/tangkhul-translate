# Contribution data-rights decision

## Current M5 decision: internal use only

Accepted corrections collected under `contribution-v1` may be stored, human-reviewed, and used
internally to improve the translator. They may **not** be redistributed as a public/open dataset
under v1.

This is the conservative reading of the committed v1 wording. It does not grant a right to publish
or sublicense contributor corrections. The exact `consent_version` remains attached to every
feedback and export record, so v1 records are never silently reinterpreted.

If the project owners later want public dataset redistribution, they must approve a new immutable
consent version (for example `contribution-v2`) that names the selected dataset terms. The server
must then accept v2 explicitly; existing v1 records remain internal-only and are not retroactively
upgraded.
